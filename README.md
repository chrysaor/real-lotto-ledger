# 로또랩 공개 기록 (real-lotto-ledger)

[로또랩](https://github.com/chrysaor/real-lotto)에서 뽑힌 번호와 매주 실제 로또 6/45 당첨번호를 대조한 결과를 공개하는 저장소입니다.
이 저장소의 파일은 서버가 자동으로 커밋합니다. 사람이 직접 고치지 않습니다.

## 무엇이 올라오나

회차마다 두 번 커밋합니다.

1. **봉인** — 토요일 20:00(KST) 판매 마감 직후. 그 회차에 사이트에서 받은 번호 전체와 그 목록의 SHA-256 해시.
   실제 추첨(20:35경)보다 먼저 커밋되므로, 당첨번호를 본 뒤에 기록을 고치지 않았다는 증거가 됩니다.
2. **정산** — 당첨번호 발표 뒤. 실제 당첨번호, 1~3등 1게임당 당첨금, 등수별 건수, "실제 복권이었다면" 당첨금 합계.

공개하는 것은 번호와 받은 시각뿐입니다. IP 주소 같은 개인 정보는 담지 않습니다.

## 직접 검증하기

- 봉인 파일의 번호 목록으로 해시를 다시 계산해 봉인 커밋의 해시와 같은지 확인할 수 있습니다.
- 봉인 커밋 시각이 그 회차 추첨 시각보다 앞서는지 커밋 이력으로 확인할 수 있습니다.
- 정산 파일의 등수별 건수는 봉인된 번호 목록과 당첨번호만으로 다시 계산할 수 있습니다.

## 폴더와 파일

회차마다 `{연도}/{추첨일}_{회차}/` 폴더 하나를 만듭니다.

```
2026/
  2026-11-14_1250/
    draws.csv     봉인: 그 회차에 받은 번호 전체
    seal.json     봉인: draws.csv의 SHA-256
    result.json   정산: 당첨번호와 등수별 건수
```

- `draws.csv` — 한 줄에 번호 하나. `id,받은 시각(유닉스 초, UTC),번호1,…,번호6`. 번호는 오름차순, id 순서로 정렬합니다.
  줄 끝은 LF이고 마지막 줄에도 LF가 붙으며 머리글은 없습니다. 번호가 없는 회차는 빈 파일입니다.
- `seal.json` — `{"round", "closes_at"(판매 마감, 유닉스 초), "total_draws", "sha256"}`. `sha256`은 `draws.csv` 파일 바이트 전체의 해시입니다.
- `result.json` — 실제 당첨번호와 보너스, 1~3등 1게임당 당첨금, 등수별 건수, 당첨금 합계, 당첨번호 출처(`source`).

봉인 시각은 따로 적지 않습니다. `seal.json`을 올린 커밋의 시각이 봉인 시각입니다.

## 검증 명령 예시

```sh
cd 2026/2026-11-14_1250
shasum -a 256 draws.csv          # seal.json의 sha256과 같아야 합니다
wc -l < draws.csv                # seal.json의 total_draws와 같아야 합니다
git log --format='%cI %s' -- seal.json   # 봉인 커밋 시각이 토요일 20:35(KST) 추첨보다 앞서야 합니다
```

## 안내

로또랩의 추첨은 가상 추첨입니다. 당첨 번호 예측이 아니며, 실제 복권 구매나 당첨을 보장하지 않습니다.
여기의 당첨금은 "그 번호가 실제 복권이었다면" 받았을 금액을 가정한 값이며, 실제로 지급된 돈이 아닙니다.
